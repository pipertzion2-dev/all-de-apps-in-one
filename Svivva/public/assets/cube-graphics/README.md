# Cube Face Graphics

This directory contains custom graphics that replace the default artwork on cube faces.

## Digital Face Graphic

Place your custom digital camouflage graphic here:

- File: `digital-camo.jpg`
- Purpose: Replaces the background image on the "Digital" cube face
- The "Digital" text will still appear on top of this graphic
- Recommended size: 1024x1024px or larger
- Format: JPG or PNG

The graphic should be the burgundy/maroon digital camouflage pattern with leaf elements.
